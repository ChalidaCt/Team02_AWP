ใน Sprint 3 ทีมเราจะสร้าง "Clickable Prototype บน Figma และผังจำลองหลังบ้าน" ที่สามารถกดจิ้มเพื่อสั่งให้อาหารและแสดงหน้าต่างสถานะสำเร็จได้จริง

-----

ผู้ใช้ตั้งเวลาให้อาหารสัตว์ผ่านแอปพลิเคชัน → ระบบประมวลผลเวลาและส่งคำสั่งไปยังเครื่องให้อาหารอัตโนมัติ → ผู้ใช้เห็นสถานะการให้อาหารและสัตว์ได้รับอาหารตรงเวลา

-----
## รายละเอียดของflow
| คำถาม | คำตอบ |
| --- | --- |
| ผู้ใช้หลักของ flow นี้คือใคร? | ผู้ที่เลี้ยงสัตว์ที่ไม่มีเวลาหรือไม่สามรถให้อาหารสัตว์เลี้ยงตรงเวลาได้ |
| input แรกของ flow คืออะไร? | ผู้ใช้กำหนดเวลาและปริมาณอาหารผ่านแอป |
| ระบบต้องประมวลผลอะไร? | ตรวจสอบเวลา ส่งคำสั่งไปยัง ESP32 และสั่งให้เซอร์โวมอเตอร์ปล่อยอาหาร |
| output ที่ผู้ใช้จะเห็นคืออะไร? | สถานะให้อาหารสำเร็จและอาหารถูกปล่อยออกจากเครื่อง |
| ทำไม flow นี้สำคัญที่สุดต่อโปรเจกต์? | เป็นฟังก์ชันหลักของโปรเจกต์ที่ช่วยแก้ปัญหาการให้อาหารสัตว์ไม่ตรงเวลา |

-----

## จุดเด่นของระบบ
- สั่งให้อาหารผ่านมือถือได้
- ตั้งเวลาให้อาหารอัตโนมัติ
- ใช้งานสะดวก
- ช่วยลดปัญหาการลืมให้อาหาร
- สามารถพัฒนาต่อยอดได้นมากขึ้น

-----

## ผลที่คาดหวัง
- ช่วยให้สัตว์เลี้ยงได้รับอาหารตรงเวลาและเพิ่มความสะดวกให้เจ้าของสัตว์เลี้ยง
