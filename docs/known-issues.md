# Known Issues 
1. HC-SR04 ยังมีความคลาดเคลื่อน
*  ค่าระดับอาหารอาจแกว่งเมื่อผิวอาหารไม่เรียบ
* ได้รับผลกระทบจากรูปร่างเม็ดอาหารและมุมสะท้อนคลื่น
2. ความแม่นยำของ Load Cell ยังมี Error เล็กน้อย
* ค่าน้ำหนักอาจคลาดเคลื่อนจากแรงสั่นสะเทือน
* ต้องมีการ Calibration ก่อนใช้งาน
3. มีความหน่วงในการสั่งงานผ่านอินเทอร์เน็ต
* การให้อาหารผ่าน Firebase ขึ้นอยู่กับความเร็วเครือข่าย Wi-Fi
* อาจมี Delay 1–3 วินาทีในบางช่วงเวลา
4. ระบบยังทดสอบกับผู้ใช้จำนวนจำกัด
* การทดลองใช้งานยังอยู่ในระดับ Prototype
* ยังไม่มีข้อมูลการใช้งานระยะยาว
5. ยังไม่มีระบบแจ้งเตือนอัตโนมัติ
* เมื่ออาหารใกล้หมด ผู้ใช้ต้องเปิด Dashboard เพื่อตรวจสอบเอง
6. Prototype ยังเป็นเวอร์ชันทดสอบ 
* โครงสร้างเครื่องยังไม่ได้ออกแบบสำหรับการใช้งานเชิงพาณิชย์
* ยังต้องพัฒนาด้านความแข็งแรงและความสวยงามของตัวเครื่อง
