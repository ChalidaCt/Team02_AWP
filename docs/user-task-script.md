# User Task Script
## User Task ของทีม
| Task No. | Task ที่ให้ผู้ใช้ทำ | สำเร็จเมื่อ | Evidence ที่จะเก็บ |
| --- | --- | --- | --- |
| Task 1 | สมมติว่าคุณต้องออกจากบ้านตั้งแต่เช้า ให้ลองตั้งเวลาให้อาหารสัตว์เลี้ยงเวลา 07:00 น. จำนวน 1 มื้อ | ผู้ใช้สามารถค้นหาฟังก์ชันตั้งเวลาและบันทึกการตั้งค่าได้สำเร็จ | บันทึกหน้าจอ (Screen Recording), บันทึกการสังเกต |
| Task 2 | สมมติว่าสัตว์เลี้ยงของคุณหิวตอนนี้ ให้ลองสั่งให้อาหารทันทีผ่านระบบ | ผู้ใช้สามารถค้นหาฟังก์ชันสั่งให้อาหารทันที และกดสั่งงานได้สำเร็จ | วิดีโอสั้น, บันทึกการสังเกต |
| Task 3 | ลองตรวจสอบสถานะอาหารในถัง และบอกว่าปัจจุบันมีอาหารเหลืออยู่เท่าไหร่ | ผู้ใช้สามารถค้นหาข้อมูลปริมาณอาหารคงเหลือ และตอบได้ถูกต้อง | บันทึกการสังเกต, ภาพหน้าจอ |
