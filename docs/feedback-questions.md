# Feedback Questions
## คำถามของทีม

| ช่วง | คำถามที่ทีมจะใช้ |
| --- | --- |
| ก่อนทดสอบ | ปกติคุณให้อาหารสัตว์เลี้ยงอย่างไร |
| ก่อนทดสอบ | คุณคาดหวังให้ระบบนี้ช่วยอะไรได้บ้าง |
| หลังทดสอบ | ส่วนไหนของแอปที่เข้าใจง่ายที่สุด |
| หลังทดสอบ | ส่วนไหนของแอปที่สับสนหรือใช้งานยากที่สุด |
| หลังทดสอบ | หากปรับปรุงได้ 1 อย่าง คุณอยากให้ปรับอะไร |
