# Test Plan
## 1. Who — จะทดสอบกับใคร
- ชะเอม (ผู้ใช้มีสัตว์เลี้ยง / กลุ่มเป้าหมายหลัก)
- เอม (ผู้ใช้มีประสบการณ์เลี้ยงสัตว์)

## 2. What — จะให้เขาทำ task อะไร
- Task 1: ตั้งเวลาให้อาหารสัตว์เลี้ยง (07:00 น. 1 มื้อ)
- Task 2: สั่งให้อาหารทันทีผ่านระบบ
- Task 3: ตรวจสอบปริมาณอาหารคงเหลือในถัง

## 3. How — จะเก็บ feedback อย่างไร
- ใช้ Google Form สำหรับเก็บ feedback หลังทำ task
- ใช้ Observation Sheet ระหว่างผู้ใช้ทำ task จริง
- สังเกตพฤติกรรม (Think Aloud) ระหว่างใช้งาน
- สัมภาษณ์สั้นหลังจบการทดสอบ

## 4. Evidence — จะมีหลักฐานอะไร
- Screen Recording ระหว่างผู้ใช้ทำ task
- ภาพหน้าจอ (Screenshot) ตอนเกิด event สำคัญ
- Observation Sheet ที่ทีมจดระหว่าง test
- คำตอบจาก Google Form
- สรุป feedback หลังการสัมภาษณ์
- 
## 5. Decision — จะใช้ feedback เพื่อตัดสินใจอะไรใน Sprint 5
- ปรับปรุง UI/UX ให้ผู้ใช้เข้าใจ Flow ง่ายขึ้น
- แก้จุดที่ผู้ใช้สับสนหรือหา feature ไม่เจอ
- ปรับลำดับขั้นตอนใน Core Flow ให้สั้นและชัดขึ้น
- ตัดหรือปรับฟีเจอร์ที่ผู้ใช้ไม่เข้าใจหรือไม่จำเป็น
- ใช้จัดลำดับ backlog สำหรับ Sprint 5 (what to fix first)
